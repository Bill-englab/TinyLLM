# 模型部署使用指南

## 🚀 推荐使用方式

### 稳定版聊天应用

**启动命令**:
```bash
python deployment/apps/stable_chat.py
```

**访问地址**: http://127.0.0.1:7869

**使用步骤**:
1. 打开浏览器访问上述地址
2. 在底部输入框输入问题
3. 按回车或点击发送
4. 第一次对话会加载模型（等待1-2分钟）
5. 之后可以进行连续的多轮对话

**特点**:
- 支持多轮对话，保持上下文
- 界面简洁，操作简单
- 稳定可靠，修复了已知问题

## 🔧 故障排除

### 常见问题

1. **模型加载失败**
   - 检查模型路径是否正确
   - 确认CUDA环境正常
   - 查看控制台错误信息

2. **中文显示乱码**
   - 使用 `stable_chat.py` 版本
   - 确保终端编码为UTF-8

3. **多轮对话失败**
   - 使用 `stable_chat.py` 版本
   - 该版本已修复历史记录格式问题

### 端口冲突

如果端口被占用，可以修改代码中的端口号：
```python
demo.launch(
    server_name="127.0.0.1",
    server_port=7870,  # 修改为其他端口
    share=False
)
```

## 📈 性能优化建议

1. **首次使用**: 第一次对话会加载模型，请耐心等待
2. **显存管理**: RTX 3070有8GB显存，适合1B参数模型
3. **并发限制**: 当前版本为单用户，多用户需要进一步开发
