## 🗂️ 文件分类说明

### 主要应用文件（apps/）
- **stable_chat.py**: 推荐使用的稳定版多轮聊天应用
- **gradio_app.py**: 完整的Gradio应用，包含参数控制
- **integrated_app.py**: 集成监控功能的应用

### 监控系统文件（monitoring/）
- **gpu_monitor.py**: GPU状态监控模块
- **performance_monitor.py**: 推理性能监控模块
- **dashboard.py**: 集成监控仪表盘

### 测试文件（tests/）
- **test_model.py**: 基础模型功能测试
- **fix_chinese_test.py**: 中文输出修复测试

### 归档文件（archive/）
这些是学习过程中的测试版本，已归档保存：
- 各种Gradio版本测试
- 不同聊天界面的实验
- 调试和故障排除的中间版本

### 文档文件（docs/）
- **使用指南.md**: 详细的使用方法和故障排除
- **项目总结.md**: 学习成果和技术总结
- **文件整理说明.md**: 本文件

### 工具文件
- **download_model.py**: 模型下载脚本
- **start_chat.bat/sh**: 便捷启动脚本
