## API和配置说明

### vLLM核心API

#### LLM类构造函数
```python
class LLM:
    def __init__(
        model: str,                    # 模型路径或HuggingFace模型名
        tokenizer: Optional[str] = None,  # tokenizer路径(可选)
        tokenizer_mode: str = "auto",      # tokenizer模式
        trust_remote_code: bool = False,    # 是否信任远程代码
        dtype: Union[str, torch.dtype] = "auto",  # 数据类型
        quantization: Optional[str] = None,    # 量化方法
        gpu_memory_utilization: float = 0.9,    # 显存使用率
        max_model_len: Optional[int] = None,     # 最大序列长度
        tensor_parallel_size: int = 1,       # 张量并行度
        # ... 更多参数
    )
```

#### SamplingParams类
```python
class SamplingParams:
    def __init__(
        n: int = 1,                    # 生成数量
        temperature: float = 1.0,        # 温度参数
        top_p: float = 1.0,             # top-p采样
        top_k: int = -1,               # top-k采样
        max_tokens: int = 16,           # 最大token数
        stop: Optional[Union[str, List[str]]] = None,  # 停止词
        # ... 更多参数
    )
```

### 关键配置参数说明

#### gpu_memory_utilization
- **作用**: 控制vLLM使用的GPU显存比例
- **默认**: 0.9 (90%)
- **调优**: 根据模型大小和需求调整
- **建议**: 0.6-0.8之间，留空间给KV Cache

#### dtype
- **作用**: 模型权重的数据类型
- **选项**:
  - `"half"`: FP16，节省显存，适合推理
  - `"bfloat16"`: BF16，平衡精度和显存
  - `"float32"`: FP32，最高精度，最大显存
- **推荐**: `"half"`用于推理

#### max_model_len
- **作用**: 模型支持的最大序列长度
- **影响**: KV Cache大小和显存占用
- **权衡**: 更大长度→更多显存
- **建议**: 根据实际需求设置，如8192或16384

### 集成GPU监控

**方法**:
```python
import pynvml

def get_gpu_info():
    pynvml.nvmlInit()
    handle = pynvml.nvmlDeviceGetHandleByIndex(0)
    memory_info = pynvml.nvmlDeviceGetMemoryInfo(handle)
    util_info = pynvml.nvmlDeviceGetUtilizationRates(handle)

    return {
        "memory_used_gb": memory_info.used / 1024**3,
        "memory_total_gb": memory_info.total / 1024**3,
        "gpu_utilization": util_info.gpu,
        "memory_utilization": util_info.memory
    }

# 使用
gpu_info = get_gpu_info()
print(f"GPU利用率: {gpu_info['gpu_utilization']}%")
```

### 性能数据收集

**模板**:
```python
class PerformanceMonitor:
    def __init__(self):
        self.metrics = []

    def record_inference(self, start_time, end_time, num_tokens):
        inference_time = end_time - start_time
        tokens_per_second = num_tokens / inference_time

        self.metrics.append({
            "time": inference_time,
            "tokens": num_tokens,
            "tps": tokens_per_second
        })

    def get_stats(self):
        if not self.metrics:
            return {}

        return {
            "avg_time": sum(m["time"] for m in self.metrics) / len(self.metrics),
            "avg_tps": sum(m["tps"] for m in self.metrics) / len(self.metrics),
            "total_tokens": sum(m["tokens"] for m in self.metrics)
        }
```
