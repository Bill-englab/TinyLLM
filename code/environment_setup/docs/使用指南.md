## 详细使用方法

### 1. vLLM基础推理

**运行测试应用**：
```bash
python apps/test_local_llama.py
```

**自定义模型路径**：
```python
from vllm import LLM, SamplingParams

# 修改模型路径
model_path = "/path/to/your/model"
llm = LLM(model=model_path)
```

**调整推理参数**：
```python
sampling_params = SamplingParams(
    temperature=0.7,      # 温度参数，控制随机性
    top_p=0.9,           # top-p采样，控制多样性
    max_tokens=256,        # 最大生成token数
    top_k=50             # top-k采样
)
```

### 2. 性能优化配置

**显存优化**：
```python
llm = LLM(
    model=model_path,
    gpu_memory_utilization=0.6,  # 调整显存使用率
    dtype='half',               # 使用FP16节省显存
    max_model_len=8192          # 限制最大长度
)
```

**并发优化**：
```python
# 批量推理
prompts = ["prompt1", "prompt2", "prompt3"]
outputs = llm.generate(prompts, sampling_params)
```

### 3. 模型选择建议

**显存分配参考**：
- **1B模型**: ~2GB显存
- **7B模型**: ~14GB显存（需要量化）
- **量化建议**: 4-bit量化可减少75%显存占用

**本地模型部署**：
```bash
# 使用本地模型
python -m vllm.entrypoints.api_server \
    --model /path/to/local/model \
    --port 8000
```

## 常见问题解答

### Q1: vLLM启动失败

**症状**：模型加载时报错
**解决方案**：
1. 检查CUDA版本：`nvcc --version`
2. 验证GPU驱动：`nvidia-smi`
3. 确认模型文件完整性

### Q2: 显存不足错误

**症状**：CUDA out of memory
**解决方案**：
```python
# 降低显存使用率
llm = LLM(model=model_path, gpu_memory_utilization=0.4)

# 或使用量化模型
llm = LLM(model=model_path, quantization="gptq")
```

### Q3: 推理速度慢

**症状**：tokens/秒低于预期
**解决方案**：
1. 启用CUDA Graph（默认开启）
2. 检查GPU利用率：`nvidia-smi`
3. 考虑使用FlashAttention优化

### Q4: 网络模型下载失败

**症状**：无法从huggingface下载模型
**解决方案**：
```bash
# 使用镜像
export HF_ENDPOINT=https://hf-mirror.com

# 或使用本地模型
python -m vllm.entrypoints.api_server \
    --model /path/to/local/model
```

## 扩展配置

### API服务器部署

**启动vLLM API**：
```bash
python -m vllm.entrypoints.api_server \
    --model /path/to/model \
    --host 0.0.0.0 \
    --port 8000 \
    --gpu-memory-utilization 0.8
```

**客户端调用**：
```python
import requests

response = requests.post(
    "http://localhost:8000/v1/completions",
    json={"model": "model", "prompt": "Hello", "max_tokens": 100}
)
```

### 多GPU配置

**张量并行**：
```python
llm = LLM(
    model=model_path,
    tensor_parallel_size=2  # 使用2张GPU
)
```
