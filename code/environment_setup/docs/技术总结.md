## 技术深度分析

### vLLM核心算法

**PagedAttention**:
- 传统的KV Cache需要连续内存块
- PagedAttention使用虚拟内存页，提高内存利用率
- 类似操作系统的内存分页机制

**Continuous Batching**:
- 动态将不同长度的请求组合处理
- 避免短请求等待长请求的padding
- 显著提高整体吞吐量

**CUDA Graph**:
- 预编译整个推理图到GPU
- 减少kernel启动开销
- 特别适用于固定大小的推理

### FlashAttention原理

**算法优化**:
- 减少HBM内存访问次数
- 利用GPU共享内存优化注意力计算
- 避免传统注意力算法的O(n²)复杂度

**性能提升**:
- 相比标准注意力有显著加速
- 特别适合长序列推理
- 在RTX 3070上表现良好
