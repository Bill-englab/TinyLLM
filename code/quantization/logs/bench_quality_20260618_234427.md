### Prompt 2: Write a Python function binary_search(arr, target) that returns the index or -1.

```
**Binary Search Function in Python**
================================

Here's a Python function that performs a binary search on a sorted array to find the index of a target element.

```python
def binary_search(arr, target):
    """
    Searches for the index of a target element in a sorted array using binary search.

    Args:
        arr (list): A sorted list of elements.
        target: The target element to search for.

    Returns:
        int: The index of the target element if found, -1 otherwise.
    """
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1
```
