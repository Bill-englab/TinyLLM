## ✅ 关键学习成果

### 反直觉认知
- [x] "量化一定更快"是误区 → INT8 在 1B 小模型上反而慢 70%
- [x] "4-bit 比 8-bit 差很多"是误区 → 现代 4-bit 精度损失 < 2%
- [x] "量化对所有模型效果一样"是误区 → 模型越大越无损
