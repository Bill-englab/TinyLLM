### 3.2 网络问题解决方案

在选择模型后，我面临的第一个大问题是网络。Hugging Face一直无法访问，这让我很头疼。

尝试了多种方法：
1. VPN - 速度太慢，不稳定
2. 镜像站 - 找到了几个，但都不太稳定
3. ModelScope - 最终的解决方案

ModelScope是阿里云的模型库，不仅速度快，而且有很多国内热门模型：

```python
from modelscope import snapshot_download, AutoModelForCausalLM, AutoTokenizer

MODEL_ID = "LLM-Research/Llama-3.2-1B-Instruct"
MODEL_PATH = "../model/llama-3.2-1b-instruct"

def download_model():
    print(f"开始通过ModelScope下载模型: {MODEL_ID}")
    print(f"保存路径: {MODEL_PATH}")

    try:
        model_dir = snapshot_download(
            MODEL_ID,
            cache_dir=MODEL_PATH,
            revision="master"
        )
        print(f"✅ 模型下载完成! 保存至: {model_dir}")

        # 加载模型进行测试
        tokenizer = AutoTokenizer.from_pretrained(model_dir, trust_remote_code=True)
        model = AutoModelForCausalLM.from_pretrained(
            model_dir,
            torch_dtype=torch.float16,
            device_map="auto",
            trust_remote_code=True
        )
        print("✅ 模型测试加载成功!")

        return model, tokenizer
    except Exception as e:
        print(f"❌ 下载失败: {e}")
        raise
```

下载过程大约花了2分钟，2.4GB的模型文件很快就下载完成了。

### 4.3 核心代码解析

**模型加载与延迟加载**

我采用了延迟加载的策略，这样Web界面可以快速启动：

```python
def load_model():
    global model, tokenizer
    if model is not None and tokenizer is not None:
        return  # 避免重复加载

    print("正在加载模型...")
    tokenizer = AutoTokenizer.from_pretrained(MODEL_PATH, trust_remote_code=True)
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token  # 避免警告

    model = AutoModelForCausalLM.from_pretrained(
        MODEL_PATH,
        dtype=torch.float16,  # 使用FP16节省显存
        device_map="auto",    # 自动分配设备
        trust_remote_code=True
    )
    print("✅ 模型加载完成！")
```

**多轮对话实现**

多轮对话是整个过程中最复杂的部分。核心是正确处理历史记录：

```python
def generate_response(message, history):
    # 第一次对话时加载模型
    if model is None or tokenizer is None:
        load_model()

    try:
        # 构建消息历史
        messages = []
        for item in history:
            # 确保item是正确的格式
            if isinstance(item, (tuple, list)) and len(item) >= 2:
                user_msg, bot_msg = item[0], item[1]
                if user_msg:  # 只有用户消息不为空才添加
                    messages.append({"role": "user", "content": user_msg})
                if bot_msg:  # 只有机器人回复不为空才添加
                    messages.append({"role": "assistant", "content": bot_msg})

        # 添加当前消息
        if message:
            messages.append({"role": "user", "content": message})

        # 使用chat template
        formatted_prompt = tokenizer.apply_chat_template(
            messages,
            tokenize=False,
            add_generation_prompt=True
        )

        # 编码输入
        inputs = tokenizer(formatted_prompt, return_tensors="pt").to(model.device)

        # 生成回复
        with torch.no_grad():
            outputs = model.generate(
                inputs.input_ids,
                attention_mask=inputs.attention_mask,
                max_new_tokens=150,
                do_sample=True,
                temperature=0.7,
                top_p=0.9,
                pad_token_id=tokenizer.pad_token_id
            )

        # 解码输出
        response = tokenizer.decode(outputs[0][inputs.input_ids.shape[1]:], skip_special_tokens=True)
        return response

    except Exception as e:
        return f"错误: {str(e)}"
```

## 第五章：技术问题解决历程

### 5.1 中文输出乱码问题

这是让我最头疼的问题之一。一开始，模型的中文输出全部是乱码：

```
你: 你好，请介绍一下你自己
模型: �������ģ�˵�...
```

我以为是模型本身的问题，但经过排查发现是编码问题：

**初步排查**：
- 检查模型是否支持中文（LLaMA是支持的）
- 检查tokenizer配置
- 检查输出编码

**深入分析**：
我发现问题出在输出编码上。Windows下的默认编码不是UTF-8，而模型输出的中文需要UTF-8编码。

**解决方案**：
```python
import sys
import io

if sys.platform == 'win32':
    sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
    sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding='utf-8')
```

加上这个设置后，中文输出完全正常了！

### 5.2 多轮对话格式问题

## 第六章：监控系统搭建

### 6.1 GPU监控系统

为了更好地理解模型的运行情况，我实现了一个GPU监控系统：

```python
import pynvml

def get_gpu_info():
    if not torch.cuda.is_available():
        return {"gpu_available": False}

    try:
        pynvml.nvmlInit()
        handle = pynvml.nvmlDeviceGetHandleByIndex(0)

        # 获取GPU利用率
        utilization = pynvml.nvmlDeviceGetUtilizationRates(handle)
        gpu_util = utilization.gpu

        # 获取温度
        temperature = pynvml.nvmlDeviceGetTemperature(handle, pynvml.NVML_TEMPERATURE_GPU)

        # 获取显存信息
        gpu_props = torch.cuda.get_device_properties(0)
        total_memory = gpu_props.total_memory / (1024**3)  # GB
        allocated_memory = torch.cuda.memory_allocated(0) / (1024**3)
        free_memory = total_memory - allocated_memory

        pynvml.nvmlShutdown()

        return {
            "gpu_name": gpu_props.name,
            "gpu_utilization": gpu_util,
            "temperature": temperature,
            "total_memory": round(total_memory, 2),
            "allocated_memory": round(allocated_memory, 2),
            "free_memory": round(free_memory, 2)
        }
    except Exception as e:
        return {"error": str(e)}
```

这个监控系统让我能实时看到GPU的运行状态。

### 6.2 性能监控系统

除了GPU状态，我还实现了性能监控：

```python
class InferencePerformanceMonitor:
    def __init__(self):
        self.inference_history = []

    def start_inference(self, prompt: str):
        self.current_inference = {
            "prompt": prompt,
            "start_time": time.time()
        }

    def end_inference(self, response: str, tokens_generated: int):
        inference_time = time.time() - self.current_inference["start_time"]

        performance_data = {
            **self.current_inference,
            "response": response,
            "tokens_generated": tokens_generated,
            "inference_time": round(inference_time, 4),
            "tokens_per_second": round(tokens_generated / inference_time, 2) if inference_time > 0 else 0
        }

        self.inference_history.append(performance_data)
        return performance_data
```

这个系统能帮我记录每次推理的性能数据。
