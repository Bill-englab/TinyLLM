## 📌 历史记录:AI Infra 缺口审查(2026-09-05)

课程制重构前,曾对本仓库做过 AI Infra 视角审查并识别六类缺口,当时折入旧阶段 3-5;
本次课程制重构将其全部纳入 8 篇体系,并新增硬件可行性评估结论(课程大纲附录 A):

| 缺口 | 落点 |
|------|------|
| 硬件与测量层(profiling/roofline) | 第1篇 |
| Kernel/算子层(Triton/FA 原理/compile/CUDA Graphs) | 第4篇 |
| 引擎内部(vLLM 源码/KV cache/chunked prefill) | 第2篇;PD 分离第6/7篇 |
| 基准方法论(P99/负载模型/能耗) | 第1篇 1.7 + 第6篇 6.3 |
| 模型规模对比(7B)与引擎横向 | 第2篇 2.7 + 第3篇 3.6 |
| 训练侧空白(SFT/LoRA/蒸馏) | 第5篇(新增,硬件可行性:1B/3B 绿,7B QLoRA 黄) |
| 分布式概念(TP/PP/NCCL) | 第7篇(概念学习) |

**关键硬件结论**(2026-09 实测,详见课程大纲附录 A):
7B 用社区预量化 GPTQ(serving 绿);自行量化/投机采样/微调限定 3B 及以下;
`.wslconfig` 设 `memory=10GB` 解锁宿主 16GB;vLLM 建独立 conda 环境。
